# Rabiu Yustech Portfolio

This is the portfolio and lead-generation site for Rabiu Yusuf (Rabiu Yustech), an eCommerce growth specialist.

**Stack:** TanStack Start, React 19, Tailwind CSS 4, shadcn/ui, Netlify (Forms and Image CDN).

## Run locally
```bash
pnpm install
netlify dev --port 8889   # or: pnpm dev
```

## Editing content
All site content lives in `src/data/site.ts` and `src/data/legal.ts`. Images are in `public/img/`.
